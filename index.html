Fundamento matemático

Ecuación de Laplace

En estado estacionario, la temperatura en el interior de la placa satisface la ecuación de Laplace. En la malla, cada punto interior se actualiza usando el promedio de sus cuatro vecinos.

∂²T/∂x² + ∂²T/∂y² = 0
Tᵢ,ⱼ = (Tᵢ₋₁,ⱼ + Tᵢ₊₁,ⱼ + Tᵢ,ⱼ₋₁ + Tᵢ,ⱼ₊₁) / 4

Proceso de cálculo

  1. Se establece una placa de 30 × 30 puntos.
  2. Se asignan las temperaturas de los cuatro bordes.
  3. Jacobi calcula una nueva temperatura para cada punto interior.
  4. Se mide el mayor cambio entre dos iteraciones consecutivas.
  5. El proceso termina cuando el error es menor que la tolerancia.
